# 纸间日记（Android 平板）

一款完全离线的个人日记 App。支持分类、多个日记本、每本多篇日记、文字、多张本地图片、日期时间、手动地点及按需获取当前位置。页面针对平板设计，文字和按钮较大；横屏显示三栏，窄屏分步显示。

## 数据和备份

- 日记文字及结构保存在设备上的 SQLite 数据库；图片在选取后复制到 App 私有目录。读取图片使用 Android 系统文件选择器提供的单次访问授权，不申请整个相册的读取权限。
- 点击“获取当前位置”时才请求前台定位权限。地点可以随时手动填写。App 不申请网络权限，不上传数据。
- “备份与迁移”可以导出包含文字和原始图片的 ZIP 文件，也可以导入 ZIP 并完整恢复。导入前会提示覆盖现有数据；读取和校验失败时原数据保留。
- 建议第一次打开时选择平板本地文件夹作为自动备份目录。编辑结束约 15 秒后会保存一份完整备份，并保留最近 3 份。该目录必须是“这台设备”或 SD 卡，不能是云盘。
- Android 卸载 App 时会删除其私有数据。因此“永久保存”需要保留导出的 ZIP 或自动备份文件；平板损坏仍可能导致本机数据丢失。建议定期把备份另存到安全位置。

## 构建与安装

使用 Android Studio 打开此目录，安装 Android SDK Platform 35 和 Build Tools 35.0.0，然后运行 `./gradlew assembleDebug`。生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，适用于 Android 8.0 及以上的平板。调试包可直接侧载安装；正式长期使用建议固定签名密钥构建发布包，避免以后因签名变化无法覆盖升级。

## 迁移步骤

1. 旧平板：“备份与迁移” → “导出完整备份”，保存 ZIP。
2. 将 ZIP 文件复制到新平板。
3. 新平板安装同一 App：“备份与迁移” → “导入备份并恢复”。
4. 在新平板重新设置自动本地备份目录。
